# Christin John — Data Engineer Portfolio

A responsive, dependency-free static portfolio for GitHub Pages. Open `index.html` locally to preview.

## Publish

Push these files to a GitHub repository. In repository Settings → Pages, select Deploy from a branch, `main`, and `/ (root)`, then save. A repository named `<username>.github.io` publishes at `https://<username>.github.io/`; other repository names publish under their repository path.

## Content review

The initial content is based on information supplied in conversation. Verify the employment wording, certification names and validity, and project descriptions before public publication. No employer source code or confidential data is included. Case studies describe professional work; they do not imply public demonstration repositories exist.

Add verified GitHub, LinkedIn, contact details, and a public resume when provided. Quantified performance claims are intentionally awaiting verification before publication.

## Files

- `index.html`: portfolio content and native expandable case studies
- `styles.css`: responsive design and accessible focus styles
- `favicon.svg`: site icon
- `.nojekyll`: serve static files directly
